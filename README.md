# 🗂️ Kanban Board Component

A modern, customizable **Kanban Board** built using **React**, **TypeScript**, and **Tailwind CSS**, featuring drag-and-drop task management, responsive design, and full Storybook documentation.

## ⚙️ Installation

Clone the repository and install dependencies:

```bash
npm install
**Start the Storybook environment:
**
npm run storybook


**Build for production:**

npm run build

**🧩 Architecture
**
This Kanban Board is structured into reusable components for scalability and maintainability.
It uses a custom React hook (useKanbanBoard) to manage board state, enabling easy task creation, editing, and status updates.

**Core Components:**

KanbanBoard – Main board layout with multiple columns.

Column – Displays tasks by their status.

TaskCard – Shows task details and allows editing/deletion.

useKanbanBoard Hook – Handles board logic and task management.

**✨ Features**

 Drag-and-drop tasks between columns

 Add, edit, and delete tasks

 Responsive design for all screen sizes

 Keyboard accessibility for better UX

 Customizable columns and task properties

 Storybook stories for isolated UI testing

**📚 Storybook Stories**

✅ Default Board – Standard layout with sample data

⚪ Empty State – Board with no tasks

📊 Large Dataset – Tests performance with many tasks

📱 Mobile View – Fully responsive design

🧠 Interactive Playground – Test props and interactivity

**Run locally:**

npm run storybook
